# api_advanced

This project is about using the Reddit API with Python and the requests
module. I get information about subreddits like the subscribers and the
hot posts.

Files:
- 0-subs.py : returns the number of subscribers of a subreddit
- 1-top_ten.py : prints the titles of the first 10 hot posts
- 2-recurse.py : returns a list with the titles of all hot posts (recursive)
- 3-count.py : counts the keywords in the hot titles (recursive)

Each file has a function, so you need to import it in another file to use it.
Example: python3 0-main.py programming
